# 邻传 0.4.1 使用说明

两台电脑把便携包完整解压到可写目录，然后各自双击 `邻传.exe`。不用安装 Python，不用浏览器，两端都能主动聊天和发送文件。

1. 接入同一个可信局域网，等待左侧显示运行邻传的设备。
2. 选择对方。聊天点击“开始聊天”，双方通过当面或电话核对验证码，一致后点击“一致，开始聊天”。
3. 下方输入消息，Enter 发送，Shift+Enter 换行。会话最多 1 小时，可点击“结束聊天”。
4. 发文件：选择文件 → 发送文件；或先选设备，直接把文件拖入右侧窗口。拖拽会立即发起请求，**不会未经对方确认直接保存**。
5. 文件批次仍需双方核对新的验证码，发送方点“一致，继续”，接收方点“一致，接收”。传输不要求先建立聊天。
6. 接收完成点顶部“接收文件夹”。支持同时聊天和传文件，双向操作相同。

窗口默认 720×580，可以缩小至 640×520 或自行放大。设置中更改设备名、选择网卡。

**范围和保存：** 单条文字最多 4 KiB，单文件最多 2 GiB，每批最多 50 个文件、合计 20 GiB；暂不支持文件夹，请先压缩。文件保存于 EXE 旁 `邻传数据/received`，文件名加随机前缀防止覆盖。聊天仅保留在内存中，关闭 App 后清空，最多缓存最近 300 条显示记录/设备；不支持离线消息、自动重发、断点续传。

**网络：** 只接受私有 IPv4/本机地址，发现用 UDP 45876，通信用 TCP 8765，HTTPS 点对点，不使用公网中继或代理，不发送遥测。接收授权与证书 pin 防止其他设备随意访问文件。验证码必须通过可信渠道核对，设备显示的名字不等于可信身份。

**防火墙：** 提示时只允许专用网络；公共网络权限不需要。程序不会自动更改防火墙。路由器访客网络/客户端隔离、企业网络、VPN 多网卡或禁止组播时可能无法发现。可在设置选正确 IPv4，再用“手动连接”填对方地址和端口。旧版 0.2.0 可继续文件互传，但聊天要求双方都是 0.3.0。

**拖拽没有反应：** 两端程序都以普通用户运行；从资源管理器拖入真实文件，别拖文件夹、ZIP 内虚拟条目或云端未落地文件。Windows 权限级别不同可能阻止拖拽。

**验证范围：** 本机真实 HTTPS 双向收发、组播发现、Tk 窗口及打包自检已验证。不同物理电脑、不同路由器和防火墙配置仍需实际验证。

## 更新软件

设置 → 软件更新 · GitHub → 检查更新。发现更高的正式版本后点击“下载新版 ZIP”；下载完成时核对 SHA-256，失败不会保留损坏文件。可打开下载文件夹，也可点击“GitHub 发布页”直接查看版本。

退出两端正在运行的邻传，解压新包，替换 EXE 与说明文档，保留原来的 `邻传数据` 文件夹，接收文件和设备名会保留。不需要删除或迁移 Git 源码。

只有主动检查或下载软件更新时才会使用公网访问 GitHub；不在后台检查，不自动覆盖或执行 EXE，不上传聊天或文件。下载版本号不高于当前版本时不会提示升级。GitHub 连接失败不影响局域网功能。

公开仓库：[powersqb/lindrop](https://github.com/powersqb/lindrop)，正式版下载在 [Releases](https://github.com/powersqb/lindrop/releases)。SHA-256 通过校验表示附件与 GitHub 发布记录一致，不等同 Windows 数字签名。
