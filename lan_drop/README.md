# 邻传 · 桌面互传

个人局域网文件传输工具。**两台 Windows 电脑各自双击 EXE，窗口显示正在运行邻传的设备，选中即可发文件，无需浏览器。**

**当前版本：0.2.0 · 更新日期：2026-10-11**

## 快速开始

1. 两台电脑都使用本版 `邻传.exe`。将便携包完整解压到可写目录，例如“文档\邻传”，不要直接在 ZIP 内运行。
2. 两台电脑接入同一可信局域网，Wi-Fi 或网线均可，然后各自双击 `邻传.exe`。启动后自动上线，不需要点击“启动服务”。
3. Windows 防火墙若提示，只允许 **专用网络**；程序不会自动修改防火墙。
4. 稍等约 2–6 秒，在左侧 **附近设备** 里选择对方。列表只显示运行邻传桌面版的设备。
5. 点击 **选择文件**，再点击 **发送给选中设备**。
6. 两边窗口会显示同一组验证码，例如 `1234-ABCD-5678-EF90`。通过当面、电话等可信方式逐段核对；一致后，发送方点击 **一致，继续发送**，接收方点击 **一致，接收**。不一致则取消或拒绝。
7. 传输完成后，接收方点击 **打开接收文件夹** 查看文件。

**双向都能发送：** 要反向传文件，只需另一台电脑选择设备和文件，按同样流程发送。双方都可以主动发起，不分“服务端”和“客户端”。

## 常用操作

| 操作 | 入口 |
| --- | --- |
| 给设备起一个容易识别的名字 | 修改顶部“我的设备名”，点击“保存” |
| 找到对方 | 左侧“附近设备”，通常自动出现；也可点击“刷新” |
| 发多个文件 | “选择文件”中多选，然后发送 |
| 取消发送 | 点击发送区域的“取消” |
| 拒绝别人发来的文件 | 接收区域点击“拒绝” |
| 中途停止接收 | 接受后按钮变为“停止接收” |
| 查看进度与结果 | 发送 / 接收进度条，以及“本次传输记录” |
| 查看保存位置 | 右上角“打开接收文件夹” |
| 结束使用 | 关闭窗口；服务和发现通知一起停止 |

## 是轻量 App 吗？

Windows 单文件 EXE，约 15 MiB，免安装。Python、Tk 和 OpenSSL 已包含在程序中，不需要另外安装运行环境；不用 Electron 或内置浏览器。不安装系统服务，不设置开机启动。

文件分块读写，不把整个文件装入内存；发送前计算 SHA-256，接收后核对。接收的文件另占磁盘空间。运行内存没有单独做性能测量。

## 文件保存位置

- 独立程序：程序旁 `邻传数据\received`。
- 源码运行：项目 `outputs\lan-drop\received`。
- 保存时保留原文件名，并加随机前缀，避免同名覆盖。
- 文件接收完成才从临时文件变为正式文件；中断或校验失败不保存不完整文件。
- 关闭程序不会删除已完成文件。请在资源管理器中自行清理。
- 文件不会自动共享给其他设备；本次传输的接收授权仅用于确认的文件。

## 找不到设备时

| 现象 | 处理 |
| --- | --- |
| 列表为空 | 确认双方都运行 **0.2.0 桌面版**，处于同一局域网，并等待几秒 |
| 电脑有多个网卡 | 顶部“网络”选择与对方同网段的 IPv4；正在传输时不能切换 |
| 窗口显示 `127.0.0.1` | 当前没有找到局域网网卡；这个地址只能本机访问 |
| 同一 Wi-Fi 仍找不到 | 检查 Windows 专用网络防火墙、访客网络或路由器的客户端隔离 |
| 网络不允许组播发现 | 点击“找不到设备？手动连接”，输入对方窗口中的 `IPv4:端口`；仍直接在 App 内传文件 |
| 启动时提示端口被占用 | 关闭本机另一个邻传实例后再启动 |
| 对方退出 | 约 8 秒内从列表消失，尚在进行的传输可能中断 |

发现使用局域网组播 UDP **45876**，文件连接默认使用 HTTPS / TCP **8765**。组播 TTL 为 1，不扫描整段 IP，不访问公网发现服务。防火墙需要允许该应用在专用网络中接收这两类流量，不要开放公网端口转发。

## 安全与限制

- 文件内容通过 TLS 1.2 或更高版本加密，客户端每次检查服务器证书的 SHA-256 指纹；无需安装系统根证书。
- 局域网发现通知不构成可信身份，设备名也可能被冒充。双方验证码绑定双方证书与本次请求，**每批传输都应通过可信渠道核对**；未核对不要确认。
- 接收端必须明确同意当前批次。授权限制到来源 IP、当前请求和已确认文件，不能利用授权浏览本机目录。
- 单文件最多 **2 GiB**；每批最多 **50 个文件 / 总计 20 GiB**。
- 不支持文件夹上传、断点续传、跨网公网中转或 IPv6。发现通常只在同一局域网网段有效。
- 文件在磁盘上不是加密存储。本机管理员仍具有系统管理权限。
- 接收确认等待最多 2 分钟；已确认的一批文件传输最多 1 小时。接收端同时处理一个批次。
- 旧版 0.1.0 浏览器便携包保留；新版设备发现和桌面互传要求双方升级，旧版不会出现在新版设备列表中。

## 验证与开发

已验证：同一电脑两个独立实例之间的真实局域网组播发现、双向批量 HTTPS 发送、中文和同名文件、空文件、拒收、未授权请求、证书指纹变化拦截、校验失败、中断清理。第二台物理电脑上的实机验证仍待完成。

源码入口：项目根目录 `启动邻传.cmd`，或 `.venv\Scripts\python.exe -m lan_drop`。诊断参数支持 `--host`、`--port`、`--name`、`--data-dir`。

构建入口：`scripts\Build-LanDrop.ps1`。独立程序自检：`邻传.exe --self-test --data-dir <报告目录>`，查看 `self-test.json` 的 `ok`。自检只发送人工测试文件，使用两个本机独立实例模拟接收确认。

官方实现资料（核对日期 2026-10-11）：[Windows 组播](https://learn.microsoft.com/en-us/windows/win32/winsock/ipproto-ip-socket-options)、[Python TLS](https://docs.python.org/3.12/library/ssl.html)。构建沿用已核实的 PyInstaller 6.22.3；[官方包索引](https://pypi.org/project/pyinstaller/)。内置 OpenSSL 当前为 3.5.7，最新上游版本待核实。
